1. Learn the purpose of <form> in HTML. Create a basic form structure with action and method.

The <form> tag is used to collect user input and send it somewhere (usually a server).

<!DOCTYPE html>
<html>
<head>
    <title>Simple Form</title>
</head>
<body>

<h2>Student Form</h2>

<form action="submit.html" method="Get">

    <label>Name:</label>
    <input type="text" name="username"><br><br>

    <label>Email:</label>
    <input type="email" name="email"><br><br>

    <label>Password:</label>
    <input type="password" name="password"><br><br>

    <input type="submit" value="Submit">

</form>

</body>
</html>

3. Use checkboxes for multiple choices, radio buttons for single choice, and number fields for numeric input.

<!DOCTYPE html>
<html>
<head>
    <title>Student Form</title>
</head>
<body>

<h2>Student Registration</h2>

<form action="submit.php" method="post">

    <!-- Text -->
    <label>Name:</label>
    <input type="text" placeholder="Enter username" required><br><br>

    <!-- Email -->
    <label>Email:</label>
    <input type="email" placeholder="Enter email" required><br><br>

    <!-- Password -->
    <label>Password:</label>
    <input type="password" placeholder="Enter password" required><br><br>

    <!-- Radio (Single choice) -->
    <label>Gender:</label><br>
    <input type="radio" name="gender" value="male"> Male<br>
    <input type="radio" name="gender" value="female"> Female<br><br>

    <!-- Checkbox (Multiple choice) -->
    <label>Skills:</label><br>
    <input type="checkbox" name="skills" value="html"> HTML<br>
    <input type="checkbox" name="skills" value="css"> CSS<br>
    <input type="checkbox" name="skills" value="js"> JavaScript<br><br>

    <!-- Number -->
    <label>Age:</label>
    <input type="number" placeholder="Enter" min="1" max="10"><br><br>

    <input type="submit" value="Submit">

</form>

</body>
</html>


4. Learn <label> for accessibility and placeholder for hints. Connect labels with inputs using for and id.


<!DOCTYPE html>
<html>
<head>
    <title>Student Form</title>
</head>
<body>

<h2>Student Registration</h2>

<form action="submit.php" method="post">

    <!-- Text -->
    <label for="name">Name:</label>
    <input type="text" id="name" placeholder="Enter username" required><br><br>

    <!-- Email -->
    <label for="email">Email:</label>
    <input type="email" id="email" placeholder="Enter email" required><br><br>

    <!-- Password -->
    <label for="password">Password:</label>
    <input type="password" id="password" placeholder="Enter password" required><br><br>

    <!-- Radio -->
    <label>Gender:</label><br>
    <input type="radio" id="male" value="male">
    <label for="male">Male</label><br>

    <input type="radio" id="female" name="gender" value="female">
    <label for="female">Female</label><br><br>

    <!-- Checkbox -->
    <label>Skills:</label><br>
    <input type="checkbox" id="html" name="skills" value="html">
    <label for="html">HTML</label><br>

    <input type="checkbox" id="css" name="skills" value="css">
    <label for="css">CSS</label><br>

    <input type="checkbox" id="js" name="skills" value="js">
    <label for="js">JavaScript</label><br><br>

    <!-- Number -->
    <label for="age">Age:</label>
    <input type="number" id="age" name="age" placeholder="Enter age" min="1" max="100"><br><br>

    <input type="submit" value="Submit">

</form>

</body>
</html>
